# 生成订单（供货合同）— 测试版说明

> 状态：**测试版，未发版**（版本号仍为 v1.0.238）
> 立项：2026-10-22，祥哥需求；样张 `靖邦-晶科鑫订单JB260310001.xls`
> 目的：先在开发版里看效果，确认后再写入正式版并打包发版

## 一句话

客户物料页 / 首页顶栏点「🧾 生成订单」→ 选客户 → 自动带出地址/联系人/该客户物料 →
填数量、单价、交期 → 生成 Excel 供货合同，存到
**`<数据目录>/客户管理/<客户>/订单/<日期>+<物料型号>+<数量>PCS.xlsx`**，公章直接贴上。

## 入口

| 位置 | 行为 |
|---|---|
| 首页顶栏「🧾 生成订单」 | 打开订单页（空客户，可搜索选客户） |
| 客户物料页「🧾 生成订单」 | 带着当前客户直接进订单页（`/order?customer=XXX`） |
| 手机端汉堡菜单 | 同首页入口 |

路由：`/#/order`（`client/src/views/OrderForm.vue`）

## 落位与命名

```
<数据目录>/客户管理/<客户名>/订单/
    中波动光-晶科鑫订单ZBDG261022001.xlsx    ← <客户中文简称>-晶科鑫订单<订单编号>
    中波动光-晶科鑫订单ZBDG261022001.pdf     ← 同一份合同的 PDF，直接发客户
```

- 文件名 = **`<客户中文简称>-晶科鑫订单<订单编号>.xlsx`**，同时导出一份同名 PDF
- PDF 用本机 Excel 导出（版式与打印预览一比一）；没装 Office / 导出失败时只留 xlsx，
  界面上会提示原因，不挡生成
- 结果卡片：**预览 PDF**（浏览器直接打开）/ **复制 PDF 文件**（系统剪贴板，微信里 Ctrl+V 就是文件）/
  下载 PDF / 下载 Excel
- **生成前预览**：顶部「👁 预览」→ 屏幕左侧小窗显示同一份合同（不落盘、不占单号），
  点小窗放大全屏，点空白处或按 ESC 关闭，确认后再点「生成订单文件」
- 行高按内容收紧（2026-10-23 祥哥要求「能一页就一页」）：4 条物料实测 1 页；超长规格才顺延
- 历史订单每单**只显示一条 PDF**：点文件名浏览器预览，点「复制」把文件放剪贴板
  （复制文件走系统剪贴板，只在 Windows 桌面版/本机浏览器显示；手机浏览器不给这个按钮）
- **简称几个字都行**（国润 2 字 / 奥斯普 3 字 / 中波动光 4 字）：订单页有「客户简称（文件名用）」
  可改，存到客户档案，下次选这家自动带出；没存过才按公司核心字号取前 2 字做建议值
- 单号前缀（GR / ASP）是另一个可改字段，同样按客户记住；文件名/单号互不影响
- 同名已存在时不覆盖，自动加 `_2`、`_3`
- 路径与「📁 客户目录」按钮、归档逻辑共用 `customerArchive.js` 的同一套规则
- 历史订单从文件名里解析「日期 / 单号」；早期测试用的「日期+型号+数量」旧文件也兼容

## 模板还原

对照样张 `靖邦-晶科鑫订单JB260310001.xls` 复刻（`server/src/utils/orderDoc.js`）：

- A4 纵向、缩放 93%、页边距与样张一致
- 7 列列宽照抄；标题「供 货 合 同」黑体 36 加粗
- 甲方/单号/乙方/地址/联系人/电话/邮箱/传真分块位置一致
- 明细表 7 列、合计行、二~十条款、供方/需方签章、签约代表/时间
- 「九、结算方式及期限」保留样张的红色
- **左上角 SJK 品牌 logo**（251×156 原图，显示 230×143 px，A1 右移 4px/下移 2px），
  行高按 logo 留足，不压标题
- **货品编码默认 1、2、3…**（按行号，数字格式），手填自定义编码就用填的
- **公章**：用的是 `D:\夏天\客户资料\晶科鑫报价单2026-5-20后.docx` 里的公司公章
  （带五角星的圆章，透明 PNG，363×364），不是样张里的业务专用章。
  按 140×140px，锚在「供方签章」行下方一点点 —— **章压住一点文字**（真实盖章的样子），
  透明底不会把文字整段盖死。位置是祥哥在示例文件里手工调好的
  （colOff 52705 / rowOff 247650 EMU），生成时原样复刻。

为还原打印宽度做了两处专门处理（见 orderDoc.js 注释）：

1. ExcelJS 默认写 `fitToWidth/fitToHeight=1`，Excel 会忽略 `scale=93` → 已清掉；
2. ExcelJS 的「常规字体」是 Calibri 11，列宽算出来比样张（黑体 12）窄 1/8 →
   生成后把 `styles.xml` 的默认字体改成黑体 12（`patchDefaultFont`）。

物料条数可 1~30 条：下方条款、签章行、公章锚点都按条数顺延；长规格自动撑高行高，不裁字。

## 可改的信息

- 乙方：名称、地址、联系人、电话、传真
- 甲方：公司名称、地址、联系人、电话、邮箱（可「保存为默认」，下次自动带出）
- **客户简称（文件名用，2~4 字都行）**、**单号前缀（字母）**、签约日期、签约代表
- 每条物料：**货品编码（默认 1、2、3…，可改）**、产品规格（可换行）、数量、
  **单价（含税/未税可切）**、**交货时间（自由文本：空 / 2周 / 2-3周 都行）**、备注
- **价格口径**：物料区右上角「含税 / 未税」切换，只改表头「金额（含税)」/「金额（未税)」，
  金额仍是 数量×单价，不做换算；按客户记住
- 条款：运输方式、运费承担、验收期限、结算方式（六~九）
- 公章：显示/隐藏、上传自己的印章、恢复默认

金额 = 数量 × 单价，合计自动求和（公式 + 缓存值，WPS/Excel 打开即显示）。
客户信息优先从「地图地址」的客户/采购联系人/收货点带出，没有则留空可手填。

## 单号规则（2026-10-22 祥哥确认）

```
公司简称 + 年月日(YYMMDD) + 001~999 顺序号
GR261022001 / GR261022002 / …
```

- 「地区不算」：`深圳市国润聚源科技有限公司` → 去地区/法人后缀/行业词 → `国润聚源` →
  取前两字拼音首字母 → **GR**；`深圳市靖邦电子有限公司` → **JB**
- 简称存在 `customers.short_name`，界面上可改，生成时保存，下一单直接用
- 猜不出来（或名字是纯数字）时界面要求手填，不硬编
- 序号按该客户当天已用到的最大序号 +1（从文件名里的单号解析）；手改单号也可以（改过就不再自动覆盖）
- 文件名 = `<客户中文简称>-晶科鑫订单<单号>.xlsx`，例：`国润-晶科鑫订单GR261022002.xlsx`

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/orders/options?customer=` | 默认甲方信息、条款、印章、下一单号、客户资料、物料清单、历史订单 |
| POST | `/api/orders/generate` | 生成并落盘（xlsx + pdf），返回文件名/路径/合计 |
| POST | `/api/orders/preview` | 同一份合同渲染成 PDF 直接返回（不落盘），生成前预览用 |
| GET | `/api/orders/list?customer=` | 历史订单（读目录） |
| GET | `/api/orders/download?customer=&name=&inline=1` | 下载（手机端也能拿）；PDF 加 `inline=1` 浏览器直接预览 |
| POST | `/api/orders/copy` | 把 PDF/Excel 复制到系统剪贴板（可直接粘到微信） |
| POST | `/api/orders/open` | 桌面端打开文件/文件夹（explorer） |
| GET/POST | `/api/orders/seal` | 读取 / 上传印章 |
| POST | `/api/orders/seal/reset` | 恢复内置印章 |
| POST | `/api/orders/defaults` | 保存甲方信息与条款默认值 |

印章自定义文件落位：`<数据目录>/模板/公章.<png|jpg|webp>`；没有就用
`server/assets/seal-jkx.png`（内置公司公章，来自上面那份 docx）。
