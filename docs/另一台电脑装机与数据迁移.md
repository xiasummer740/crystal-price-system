# 另一台电脑：装新版 + 旧数据自动升级

> 适用场景：那台电脑上装的是**老版本**、数据是**旧格式**，现在要换成新版。
> 新版启动时会自动把旧格式整理成新格式，**不需要手工搬文件**。

---

## 一、装机前（在那台电脑上做）

### 1. 先把旧版软件完全关掉

旧版和新版同时开着，两个程序会各写一份数据库、互相覆盖。装之前务必先退出旧版。

> 安装包自己也会强杀旧进程（`customCheckAppRunning`），但「先手动关干净」仍然更稳。

### 2. 找到旧数据目录在哪

数据目录就是那个里面带 `数据库` / `规格书` / `记事图片库` 等子文件夹、名字叫 **`晶振报价管理系统`** 的文件夹。

在这台电脑上，用文件资源管理器搜 `data.db`，或者按下面的顺序找：

| 优先级 | 位置 |
|---|---|
| 1 | 旧版 exe 所在目录旁边 |
| 2 | `我的文档\晶振报价管理系统` |
| 3 | `桌面\晶振报价管理系统` |
| 4 | `下载\晶振报价管理系统` |
| 5 | `C:\Users\<用户名>\AppData\Local\crystal-price-system\data` |

**把找到的完整路径记下来**，下一步要用。

> 判断依据：文件夹里应该有 `数据库\data.db` 这个文件。

---

## 二、装新版（关键只有一步）

双击新版安装包，一路下一步。**只有「数据目录」那一步要留神。**

### 情况 A：安装过程**没有**弹「数据要放到 D 盘或 E 盘吗？」

说明那台电脑上已经有数据目录记录了，新版会**直接沿用旧目录**，什么都不用管。跳到第三步。

### 情况 B：弹出了「数据要放到 D 盘或 E 盘吗？」

这一步决定数据放哪，**选错了新版会打开一个空库**：

- 选 **「是」** → 弹出文件夹选择框 → **选中第一步记下的那个旧目录的「上一级」**
  - 例：旧目录是 `D:\工作\晶振报价管理系统` → 就选 `D:\工作`
  - 弹窗说明里写了它会自己在里面建 `晶振报价管理系统`，所以**只选到上一级**，别选到 `晶振报价管理系统` 本身
- 选 **「否」** → 数据放 `我的文档\晶振报价管理系统`
  - **只有当地一步记下的旧目录正好是 `我的文档\晶振报价管理系统` 时才能选「否」**

> ⚠️ 为什么这一步是坑：安装包一旦写下「数据目录」，新版启动时就直接认它，
> **不会再去别处找旧数据**。所以这一步指错，新版就看不到旧数据了。

---

## 三、装完第一次启动（自动升级发生在这里）

新版**每次启动**都会自动跑一次归档整理，第一次跑时会把旧格式整个搬到新格式。

跑完在**数据目录里**会生成一份报告：**`客户资料归档报告.txt`**。打开它应能看到：

```
【已归档】
  客户物料规格书：… 个
  报价规格书：… 个
  客户物料图片：… 个
  报价备注图：… 个
  记事附件：… 个
  记事更新图：… 个
  清理旧位置的重复文件：… 个

【数据库指向的文件找不到】0 条
【搬迁失败】0 条
```

**验收就两条：`找不到` 是 0、`失败` 是 0。**

### 搬迁前会自动整份备份

删旧文件**之前**先备份，备份在数据目录的 `备份\归档前-<时间戳>\` 里。
不满意可以整份退回去。

### 旧目录不会被清空

报告最后会写「旧目录未清空」——旧文件夹原样留着，还能只读查看。
里面剩几个文件是正常的：**数据库里没有任何记录引用它们**，软件不知道它们归谁，
所以不猜、不搬、不删。确认新结构没问题后可以自己删掉旧文件夹。

---

## 四、兜底：万一打开是空库 / 看不到旧数据

说明第二步的数据目录指错了。不用重装：

1. 打开新版软件 → 菜单里找 **「切换数据目录」**
2. 指向第一步记下的那个旧目录
3. 软件会重启，重启时自动在旧目录上跑迁移

先确认路径没错，再动手。

---

## 五、这套流程验证到什么程度

本次修复是在**从这台电脑导出的真实旧数据副本**上实测过的：

| 检查项 | 结果 |
|---|---|
| 全量引用核对 | 401 条引用**全部**落到真实文件，断链 **0** |
| 搬迁失败 | **0** |
| 删源文件可恢复性 | 373 个被删文件，**373 个**在备份里按内容 md5 找得到，**0 个**漏备份 |
| 重跑（幂等） | 第二遍报告为「（无）」，数据库 md5 与备份数均未变 |
| 界面实看 | 记事详情里的图片按磁盘原尺寸正常渲染 |

> ⚠️ 但**正式数据从没被公开版本迁过**：上面全部在沙箱副本上跑，
> 真实生产数据目录一个字节未动。所以第一次在那台电脑上跑正式数据时，
> **仍然要照第三步看报告核对**。

---

## 六、如果那台电脑上已经装过新版

新版每次启动都会自动跑迁移，跑第二遍是空转（报告显示「（无）」），**不会重复搬、不会重复删**。
所以：直接覆盖安装即可，不用先卸旧版、不用先动数据。
