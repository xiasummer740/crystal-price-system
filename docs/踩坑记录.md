> 最后更新：2026-11-09（v1.0.288）

## 1. 在线升级下载只有 100KB/s（2026-11-09，v1.0.288）

**现象**
- 后台下载新版本长期停在 100KB/s 左右，以前很快；有时直接卡住不动。

**原因**
- 更新下载走的是 Node 的 `https.get()` 直连 `github.com`，**不会使用 Windows 系统代理**。
- 这台机器访问 GitHub 需要代理（`127.0.0.1:10808`）；浏览器/autoUpdater 走代理所以快，Node 直连就被限速。
- autoUpdater 失败后会回退到 `directDownload()`，这条路径正是 Node 直连 —— 所以「看起来一直在下，但很慢」。

**解决**
- `electron/updater.js` 新增 `downloadOnceNet()`：优先用 Electron 的 `net.request()` 下载（跟随系统代理），失败再退回 Node `https`。
- 保留断点续传、进度上报、文件大小校验。

**验证**
- 打包版启动正常；下载逻辑无法在无更新时实测，按「代理可用时走 net」的路径验证。
- 排查命令：`Invoke-WebRequest -Method Head -Proxy http://127.0.0.1:10808 <安装包URL>` 能 200，直连超时。

**备注**
- 如果用户机器没开代理/VPN，走 net 也快不了，这是网络本身的问题，不是程序。

## 2. 升级安装每次都要点很多「下一步」（2026-11-09，v1.0.286）

**现象**
- 在线升级弹出 NSIS 安装向导，要依次点欢迎、目录、安装、完成。

**原因**
- `package.json` 里 `nsis.oneClick=false`（向导模式），更新时只用 `--updated` 启动安装器，没有静默参数。

**解决**
- 安装器启动参数改为 `['/S', '--updated', '/D=<当前安装目录>']`。
- `/S` = NSIS 静默；`/D=` 必须是**最后一个参数**且不能加引号；安装目录取 `path.dirname(app.getPath('exe'))`。
- 安装完成后 NSIS 默认 `runAfterFinish` 会重新打开程序。

**验证**
- 手动用 `setup.exe /S /D=D:\software\crystal-price-system` 安装成功，注册表版本变为 1.0.288，原数据目录不变。

**注意**
- 静默逻辑写在 1.0.286 里，所以 **1.0.286 本身还要手动装一次**，从它升级到下一版才无感。

## 3. 公司资料拖拽上传，多出一个「未分类」副本（2026-11-09，v1.0.285）

**现象**
- 拖一个文件进资料文件夹，文件夹里有一份，「未分类」里也多一份。

**原因**
- 外层 `CompanyDocs.vue` 根节点有 `@drop`/`@paste` 上传逻辑（上传到当前客户、`folder_id=0`、分类「开票资料」）；
- 内层 `CompanyDocFolders.vue` 也处理拖拽 → 同一次拖拽触发两次上传。

**解决**
- 外层 `onDragOver` / `onDrop` / `onPaste` 开头判断 `e.target.closest('.cdf')`，在文件夹组件内部时直接 return。

**验证**
- Playwright 拖一次文件，`/company-docs/upload` 请求数 = 1。

## 4. 客户文件 Ctrl+V 粘贴，文件重复两份（2026-11-06，v1.0.281）

**现象**
- 粘贴一次出现 `xxx (1).pdf`。

**原因**
- `CustomerFiles.vue` 同时在面板上 `@paste` 和 `window.addEventListener('paste')` 注册了监听，一次粘贴执行两次 `doUpload`。

**解决**
- 删掉 window 全局监听，只保留面板内一次；输入框/文本域的粘贴直接放行。

**验证**
- 模拟一次 paste 事件，上传请求 = 1。

## 5. 客户物料页打开报 `Cannot access 'C' before initialization`（2026-10-29，v1.0.263）

**现象**
- 更新到 1.0.262 后，客户物料页面白屏 + 红条报错。

**原因**
- 新增的 `watch(() => [form.value.material_code...])` 写在了 `const form = ref(...)` **之前**；
- Vue 注册 watch 时会立刻执行 getter，此时 `form` 还在 TDZ（暂时性死区）。

**解决**
- 把 watch 移到 `form` 声明之后（`openForm` 之前）。

**教训**
- 任何 `watch`/`computed` 只要顶层立即执行，就必须放在它依赖的变量声明之后。
- 构建不会报这个错，必须真机打开页面才能发现。

## 6. 地图「去定位」报 `v.setView is not a function`（2026-10-29，v1.0.260）

**现象**
- 点智能定位/去定位，红色报错。

**原因**
- 代码里混入了 Leaflet 的 `map.setView([lng,lat], zoom)`，但 `map` 是高德 AMap 实例，没有这个方法。

**解决**
- 全部换成高德接口：`setZoomAndCenter(zoom, [lng, lat])`（封装为 `mapSetView`）。

**验证**
- 定位后视角正常，无报错。

## 7. 地图搜索选点，钉子和实际位置偏移几百米（2026-10-29，v1.0.260）

**现象**
- 搜索地址选中后，标记位置和实际地址对不上，要手动拖。

**原因**
- 高德搜索/POI 返回 **GCJ02** 坐标，直接当 WGS84 存库；显示时又做了一次 WGS84→GCJ02，等于偏移两次。

**解决**
- 选点入库前统一 `gcj02ToWgs84`；显示时再 `wgs84ToGcj02`。
- 地图点击、搜索选点、智能定位三条路径统一走同一转换。

## 8. 客户文件删除确认框看不见、点不到（2026-11-04，v1.0.275）

**现象**
- 点删除，确认框在页面下方/被弹窗盖住。

**原因**
- 客户文件弹窗 `z-index: 3500`；Vant `showConfirmDialog` 默认 `z-index: 2000`，被压在下面。

**解决**
- 所有 `showConfirmDialog` 传 `zIndex: 4000`（删除文件、删除文件夹、非空强删）。

## 9. 空文件夹删不掉（2026-11-02，v1.0.272）

**现象**
- 界面显示 0 个文件，点删除提示失败。

**原因**
- 文件夹里有 `Thumbs.db` 等隐藏/系统文件；列表过滤了 `.` 开头文件，但后端 `readdirSync().length` 算上了。

**解决**
- 后端返回 `needForce: true` + 「还有 N 个文件」；前端二次确认后带 `force` 删除（`fs.rmSync(recursive)`）。

## 10. 备选物料保存后丢失交期/规格书（2026-11-06，v1.0.279）

**现象**
- 备选填了交期/规格书，保存再打开没了。

**原因**
- 后端保存 `alternates` 时过滤条件只看 `material_name || factory`，只填了编码/交期/规格书的备选会被丢掉。

**解决**
- 过滤条件扩到 `jkx_code || material_code || material_name || factory || cost_price || lead_time`。

## 11. 美元报价出现「含税价」（2026-11-04，v1.0.277/278）

**现象**
- 最近报价显示 `0.0723含税`，但币种是 USD；成本价被当成人民币。

**原因**
- 系统原来不区分币种，含税/未税都能填。

**解决**
- 业务规则：**USD 只有未税价，CNY 才有含税/未税**。
- 前端：USD 时隐藏含税价输入；保存/编辑时清空 `price_with_tax`。
- 后端：`prices.js` 新增/编辑时 USD 强制 `price_with_tax = null`。
- 历史数据：启动迁移 `UPDATE material_prices SET price_with_tax=NULL WHERE currency='USD'`（v1.0.278，沙箱清掉 85 条）。

## 12. 窄窗口/浏览器里顶部导航整排消失（2026-11-02，v1.0.271）

**现象**
- 用域名在浏览器打开，顶栏只剩 logo，看不到功能按钮。

**原因**
- 窗口宽度 ≤768 时CSS 把 `.hide-mobile` 全部 `display:none`，只留一个不显眼的汉堡图标；用户没意识到。

**解决**
- ≤1100 时顶栏下方常驻一条横向导航（客户物料/地图/订单/公司资料/报价单/更多）。
- 汉堡按钮加「菜单」文字。

## 13. Electron 打包版启动即退（历史，v1.0.240）

**现象**
- 安装后双击没反应，日志也没有。

**原因**
- electron-builder 漏打 9 个运行时依赖（`call-bind-apply-helpers` 等）；
- 环境里残留 `ELECTRON_RUN_AS_NODE=1`，Electron 以 Node 模式跑主进程。

**解决**
- `asar:false` + `extraResources` 补齐依赖；启动脚本/测试前 `Remove-Item Env:ELECTRON_RUN_AS_NODE`。
