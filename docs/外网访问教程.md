# 外网访问教程

> 让手机/家里/外地任何网络都能用域名访问你电脑上的晶振报价管理系统。
> 方案：**Cloudflare Tunnel**（免费、无需公网 IP、自动 HTTPS）。

---

## 整体原理

```
手机 (4G/外网 WiFi)
        │
        │  https://sjk-crystal.你的域名
        ▼
   Cloudflare 全球网络（自动 HTTPS）
        │
        │  加密反向通道（cloudflared 主动外连）
        ▼
   你家电脑 (运行 cloudflared 服务)
        │
        │  http://localhost:3266
        ▼
   晶振报价管理系统
```

**优势**：
- 不需要公网 IP / 不用配置路由器
- 域名固定不变，永久有效
- 流量经 Cloudflare HTTPS 加密
- 完全免费（除了域名年费约 ¥50）

## 前置准备（一次性配置）

需要 4 样东西：
1. ✅ 一个域名（去阿里云/腾讯云/Namecheap 买，约 ¥50/年）
2. ✅ 一个 Cloudflare 账号（免费注册）
3. ✅ 域名 NS 接入 Cloudflare（DNS 服务器改成 Cloudflare 的）
4. ✅ cloudflared.exe（已包含在本仓库 [Releases](https://github.com/xiasummer740/crystal-price-system/releases) 或自行下载）

## 第一阶段：注册 Cloudflare + 接入域名

### 1.1 注册 Cloudflare 账号

打开 https://dash.cloudflare.com/sign-up 注册，邮箱验证即可。

### 1.2 把域名接入 Cloudflare

1. 登录 Cloudflare → 首页点 **Add a site**
2. 输入你的域名（不带 www，比如 `example.com`）
3. 选 **Free** 套餐（完全够用）
4. Cloudflare 会扫描你域名的现有 DNS 记录，下一步
5. **关键步骤**：Cloudflare 会给你两个 NS（nameserver）地址，长这样：
   ```
   anna.ns.cloudflare.com
   bob.ns.cloudflare.com
   ```
6. **去你买域名的地方**（阿里云/腾讯云/Namecheap），把域名的 NS 改成上面两个
   - 阿里云：控制台 → 域名 → 域名列表 → 管理 → DNS 修改
   - 腾讯云：控制台 → 域名注册 → 管理 → 修改 DNS
7. 改完等 5-30 分钟，Cloudflare 那边会显示 **Active**

## 第二阶段：创建 Tunnel

### 2.1 进入 Zero Trust 控制台

打开 https://one.dash.cloudflare.com/

- 首次进入会让你创建一个 **Team Name**（随便填，比如 `crystal-team`）
- 选 **Free** 套餐（每月 50 用户免费，自用足够）

### 2.2 创建 Tunnel

1. 左侧菜单 → **Networks** → **Tunnels**
2. 点 **Create a tunnel**
3. Connector type 选 **Cloudflared**，下一步
4. **Tunnel name** 填 `crystal-tunnel`，点 **Save tunnel**
5. **关键**：下一页会显示安装命令，长这样：
   ```
   cloudflared.exe service install eyJhbGciOiJIUzI1NiI...
   ```
   **复制 `eyJh...` 后面那一大串 token**（约 200 字符），等会儿用

### 2.3 配置 Public Hostname

继续在 Tunnel 创建向导：

1. 下一步进入 **Public Hostname** 配置
2. 填写：
   - **Subdomain**: `sjk-crystal`（或你想要的子域名）
   - **Domain**: 选你刚接入 Cloudflare 的域名
   - **Type**: `HTTP`
   - **URL**: `localhost:3266`
3. 点 **Save tunnel**

这一步后，Cloudflare 会自动创建 DNS CNAME 记录：
```
sjk-crystal.example.com → CNAME → <tunnel-uuid>.cfargotunnel.com
```

## 第三阶段：本机安装 cloudflared 服务

### 3.1 下载 cloudflared.exe

打开 https://github.com/cloudflare/cloudflared/releases/latest

下载 `cloudflared-windows-amd64.exe`，约 50MB

放到 `D:\software\cloudflared\cloudflared.exe`（路径固定，本仓库脚本读这个）

### 3.2 用本仓库脚本一键安装

1. 把本仓库的 `scripts/tunnel/install-service.bat` 复制到 `D:\software\cloudflared\` 同目录
2. **右键 → 以管理员身份运行**
3. 按提示**粘贴你在第 2.2 步复制的 token**，回车
4. 看到 `✓ 安装成功！服务已启动并设为开机自启` 即可

### 3.3 验证

打开 https://one.dash.cloudflare.com/ → Networks → Tunnels

应该看到 `crystal-tunnel` 状态变为 🟢 **Healthy**

## 日常使用

### 开机自动启动

✅ cloudflared 已安装为 Windows 服务 → **自动开机启动**，无需手动操作

❗ 晶振系统本身需要单独开机启动：
- Win + R → `shell:startup` → 把晶振系统的快捷方式拖进去

### 查看 Tunnel 状态

双击 `scripts/tunnel/check-status.bat`

### 重启服务

管理员 PowerShell：
```powershell
Restart-Service Cloudflared
```

### 卸载服务

管理员双击 `scripts/tunnel/uninstall-service.bat`

## 常见问题

### 错误 1033（Argo Tunnel error）

**原因**：DNS 解析到的 tunnel 没有活跃 connector。即"域名指向的服务下线了"。

**排查**：
1. `Get-Service Cloudflared`（PowerShell）—— 看服务是否 Running
2. 没 Running → `Start-Service Cloudflared`
3. 服务不存在 → 重新运行 `install-service.bat`
4. Cloudflare 后台 Tunnel 显示 Inactive → 重启服务

### 错误 502 Bad Gateway

**原因**：tunnel 在线但后端 `localhost:3266` 没响应。

**排查**：晶振系统没启动 → 双击桌面快捷方式启动。

### 错误 530

**原因**：DNS 解析有问题。

**排查**：去 Cloudflare 后台 → DNS → 检查 `sjk-crystal` 这条 CNAME 是否存在、是否 "已代理"（橙色云朵）。

### 公司/学校网络访问不了

**原因**：部分企业防火墙屏蔽 Cloudflare 边缘节点。

**解决**：换 4G / 家里 WiFi 试。或者用 Cloudflare 的备用域名（在 Tunnel 配置加多个 hostname）。

### Tunnel 偶尔断线

**原因**：cloudflared 进程崩了或网络波动。

**解决**：服务模式有自动重连，等几秒应该自己恢复。如果一直不恢复，重启服务：
```powershell
Restart-Service Cloudflared
```

## 安全建议

**当前配置 = 公网可访问，无密码**。如果数据敏感，强烈建议加一层访问控制：

### 方案 A：Cloudflare Access（推荐）

Cloudflare 后台 → Zero Trust → Access → Applications → Add an application

- 选 Self-hosted
- 输入 `sjk-crystal.你的域名`
- Policy 加一条：邮箱白名单（只允许某些邮箱访问，访问时会要求邮箱验证）

完全免费，最多 50 用户。

### 方案 B：在晶振系统内加密码

修改 `server/src/index.js` 加 basic auth 中间件（需要写代码）。

## 多设备 / 团队使用

如果多人共用，建议：
1. Tunnel 不变（一个就够）
2. Cloudflare Access 加邮箱白名单，每人用自己邮箱登录
3. 不要泄露域名给无关人员

## 备份提醒

⚠️ **Tunnel token 等于钥匙**，不要泄露/不要传到公开 git 仓库。

如果不小心泄露：
1. 去 Cloudflare 后台 → Tunnels → crystal-tunnel → 重新生成 token
2. 本地重新跑 `install-service.bat` 粘贴新 token
