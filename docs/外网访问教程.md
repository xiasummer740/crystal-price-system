# 外网访问教程

> 让手机在外地（4G / 公司 WiFi）也能用域名访问晶振系统。
> 方案：**Cloudflare Tunnel**（免费 / 自动 HTTPS / 域名固定不变）。

---

## 🚀 小白 3 步搞定（推荐）

### 第 1 步：找到脚本

底部有快捷方式，**右键 → 打开文件所在位置**，进入 `resources\scripts` 文件夹。

（路径大概是 `%LOCALAPPDATA%\Programs\晶振报价管理系统\resources\scripts\`）

### 第 2 步：右键 → 以管理员身份运行

右键 `一键配置外网访问.bat` → 以管理员身份运行。

脚本会自动：
- ✅ 下载 cloudflared.exe
- ✅ 打开 Cloudflare 后台引导你复制 Token
- ✅ 弹出输入框让你粘贴 Token
- ✅ 把 cloudflared 装成 Windows 服务（**开机自启**）
- ✅ 把晶振系统也设置成**开机自启**

### 第 3 步：按弹窗提示粘贴 Token

去 Cloudflare 后台复制 Token（脚本会自动打开浏览器）：
```
登录 https://one.dash.cloudflare.com/
  → Networks（网络）
  → Tunnels（隧道）
  → crystal-tunnel
  → Configure（配置）
  → Install connector（安装连接器）
  → Windows + 64-bit
  → 复制 eyJh... 那一大串（约 200 字符）
```

复制好回到脚本弹的输入框，粘贴 → 回车 → **完事** 🎉

---

## ✅ 完成后

手机打开你的隧道域名（比如 `https://sjk-crystal.你的域名`），应该能直接用。

**下次开机**：cloudflared 和晶振系统都会自动启动，不用手动操作。

## ❓ 常见问题

### 报错 1033（Argo Tunnel error）

**原因**：cloudflared 服务没运行 / 进程死了

**修复**：用管理员 PowerShell 跑：
```powershell
Restart-Service Cloudflared
```

或重新双击 `一键配置外网访问.bat` 跑一次。

### 报错 502 Bad Gateway

**原因**：晶振系统没启动

**修复**：双击桌面图标启动晶振系统

### 想取消开机自启

- 取消 cloudflared 服务 → 管理员双击 [`scripts/tunnel/uninstall-service.bat`](../scripts/tunnel/uninstall-service.bat)
- 取消晶振开机自启 → 双击 [`scripts/startup/取消开机自启.bat`](../scripts/startup/取消开机自启.bat)

### 想看 Tunnel 状态

双击 [`scripts/tunnel/check-status.bat`](../scripts/tunnel/check-status.bat)

## 🔧 从零开始（如果还没有 Cloudflare / 域名 / Tunnel）

如果你**还没**配置好 Cloudflare Tunnel，需要先一次性做完下面 3 件事：

<details>
<summary>展开看一次性配置（约 30 分钟）</summary>

### A. 注册 Cloudflare 账号

打开 https://dash.cloudflare.com/sign-up 注册

### B. 买域名 + 接入 Cloudflare

1. 去阿里云/腾讯云/Namecheap 买一个域名（约 ¥50/年）
2. Cloudflare 首页 → **Add a site** → 输入域名 → 选 **Free**
3. Cloudflare 会给你两个 NS 地址，去**域名注册商**改 NS 为这两个
4. 等 5-30 分钟，Cloudflare 显示 **Active** 即可

### C. 创建 Tunnel

1. https://one.dash.cloudflare.com/ → 创建 Team（免费）
2. 左侧 **Networks** → **Tunnels** → **Create a tunnel**
3. Connector type 选 **Cloudflared**
4. Tunnel name 填 `crystal-tunnel`
5. 进入 **Public Hostname** 配置：
   - Subdomain: `sjk-crystal`（自己取）
   - Domain: 你刚接入的域名
   - Type: `HTTP`
   - URL: `localhost:3266`
6. 保存

做完以上 3 步，回到本文档顶部 **小白 3 步搞定** 即可。

</details>

## 🔒 安全提醒

**当前域名 = 公网可访问，无密码**。建议加一层访问控制：

Cloudflare 后台 → **Zero Trust** → **Access** → **Applications** → **Add an application**：
- 选 Self-hosted
- 域名 `sjk-crystal.你的域名`
- Policy 加邮箱白名单 → 只有白名单邮箱能访问

免费，最多 50 用户。
