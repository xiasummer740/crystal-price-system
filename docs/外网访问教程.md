# 外网访问教程

> 让手机在外地（4G / 公司 WiFi）也能用域名访问晶振系统。
> 方案：**Cloudflare Tunnel**（免费 / 自动 HTTPS / 域名固定不变）。

---

## 🚀 一键配置（推荐）

### 第 1 步：准备 3 样东西

运行脚本前，先去 Cloudflare 后台准备 2 个 Token + 确认域名：

**Cloudflare API Token**

1. 打开 https://dash.cloudflare.com/profile/api-tokens
2. 点 **Create Token** → **创建自定义令牌**
3. 权限加 4 条：

| 类型 | 权限 |
|------|------|
| Zone → DNS | Edit |
| Zone → DNS | Read |
| Account → Cloudflare Tunnel | Edit |
| Account → Cloudflare Tunnel | Read |

4. Zone Resources 选 **All zones**（或指定你的域名）
5. 点继续 → **创建令牌** → 复制保存（只显示一次！）

**Cloudflare Tunnel Token**

1. 打开 https://one.dash.cloudflare.com/
2. Networks → Tunnels → **crystal-tunnel** → Configure
3. 顶部 Tab 切到 **Install connector**
4. 选 Windows + 64-bit
5. 复制 `eyJh...` 那一大串（约 200 字符）

**确认域名**

你的域名已接入 Cloudflare（Zero Trust 也开通了）。

---

### 第 2 步：找到脚本

桌面底部快捷方式，**右键 → 打开文件所在位置**，进入 `resources\scripts` 文件夹。

（路径大概是 `%LOCALAPPDATA%\Programs\晶振报价管理系统\resources\scripts\`）

---

### 第 3 步：右键运行

右键 `一键配置外网访问.bat` → **以管理员身份运行**。

脚本会依次自动完成 6 件事：

```
[1/6] 检查/下载 cloudflared.exe（~50MB）
[2/6] 用 API Token 自动配置 DNS（创建 CNAME + Tunnel Public Hostname）
[3/6] 打开浏览器引导复制 Tunnel Token
[4/6] 弹出输入框粘贴 Tunnel Token
[5/6] 安装 Windows 服务 + 设置开机自启
[6/6] 等待 10 秒 → 验证外网能否访问
```

全部完成后，手机打开 `https://你的子域名.你的域名` 即可。

---

## ✅ 完成后

**下次开机**：cloudflared 和晶振系统都会自动启动，不用手动操作。

**重新配置**：再跑一次脚本即可，会自动清理旧 DNS 记录、重新创建。

## ❓ 常见问题

### 报错 503 Service Unavailable

**最常见原因**：DNS 记录不对（指向了普通 Cloudflare IP 而不是 Tunnel）。

**自动修**：重新跑一遍 `一键配置外网访问.bat`，脚本会用 API 自动修复 DNS。

**手动修**：去 Cloudflare DNS 页，删掉 `sjk-crystal` 的 A 记录，换成：
```
类型: CNAME   名称: sjk-crystal   目标: <tunnel-id>.cfargotunnel.com   代理: 橙色云朵
```

### 报错 1033 Argo Tunnel Error

**原因**：cloudflared 服务没运行 / 进程死了

**修复**：管理员 PowerShell 跑：
```powershell
Restart-Service Cloudflared
```

### 报错 502 Bad Gateway

**原因**：晶振系统没启动

**修复**：双击桌面图标启动晶振系统

### 想取消开机自启

- 取消 cloudflared 服务 → 管理员双击 `resources\scripts\tunnel\uninstall-service.bat`
- 取消晶振开机自启 → 双击 `resources\scripts\startup\取消开机自启.bat`

### 想看 Tunnel 状态

双击 `resources\scripts\tunnel\check-status.bat`

## 🔧 从零开始（如果还没有 Cloudflare / 域名 / Tunnel）

如果你**还没**配置好 Cloudflare，需要先一次性做完下面 4 件事（约 30 分钟）：

<details>
<summary>展开看一次性配置</summary>

### A. 注册 Cloudflare 账号

打开 https://dash.cloudflare.com/sign-up 注册

### B. 买域名 + 接入 Cloudflare

1. 去阿里云/腾讯云/Namecheap 买一个域名（约 ¥50/年）
2. Cloudflare 首页 → **Add a site** → 输入域名 → 选 **Free**
3. Cloudflare 会给你两个 NS 地址，去**域名注册商**改 NS 为这两个
4. 等 5-30 分钟，Cloudflare 显示 **Active** 即可

### C. 开通 Zero Trust

1. 打开 https://one.dash.cloudflare.com/
2. 创建 Team（选 Free，最多 50 用户，够用）

### D. 创建 Tunnel

1. Zero Trust 左侧 **Networks** → **Tunnels** → **Create a tunnel**
2. Connector type 选 **Cloudflared**
3. Tunnel name 填 `crystal-tunnel`（必须用这个名字！脚本硬编码了）
4. 跳过 Public Hostname（脚本会自动配置）
5. 保存

做完以上 4 步，回到本文档顶部 **一键配置** 即可。

</details>

## 🔒 安全提醒

**当前域名 = 公网可访问，无密码**。建议加一层访问控制：

Cloudflare 后台 → **Zero Trust** → **Access** → **Applications** → **Add an application**：
- 选 Self-hosted
- 域名 `sjk-crystal.你的域名`
- Policy 加邮箱白名单 → 只有白名单邮箱能访问

免费，最多 50 用户。
