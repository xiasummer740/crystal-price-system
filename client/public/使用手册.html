晶振报价管理系统 v1.0.2

晶振物料价格记录查询系统 — 支持 PC 桌面端 + 手机 PWA 访问。

快速开始

便携版

双击 晶振报价管理系统-便携版-v1.0.2.exe 即可运行。数据自动保存在同目录的 data/ 文件夹。

安装版

运行安装程序，按向导完成安装。卸载时可选是否保留数据。

手机端访问

确保手机和电脑在同一 WiFi 网络，浏览器访问：http://电脑IP:3266（电脑 IP 在 PC 端页面底部显示）。

iPhone Safari 打开后，点「分享 → 添加到主屏幕」可安装为 PWA 应用。

报价管理（PC 端主页面）

新增报价

点击 ＋ 新增报价 → 填写信息 → 提交记录。所有字段均可选填。

编辑报价

  • 单条记录：点击 改 → 修改 → 保存修改
  • 多条同款：点击 改 → 弹窗展示全部明细 → 逐条编辑
  • 另存为新记录：基于现有记录创建新记录，原记录不动

查看同款汇总

方式一：点击蓝色 物料编码 → 弹窗按工厂分组展示全部报价。
方式二：点击橙色 X厂 X条 标签。

编辑产品参数（批量更新）

弹窗中点击 ✎ 产品参数 → 修改 → 保存。所有同款记录的规格同步更新。

删除

  • 单条删除：点击 删
  • 批量删除：勾选多条 → 删除 N → 按筛选条件一键全删
  • 恢复：顶部导航 回收站 → 恢复或彻底删除

筛选数据

方式操作
关键词搜索顶部输入框，输入后自动防抖 350ms
下拉筛选工厂/报价人/币种/品类下拉菜单 + 日期范围
列筛选点击表头 ▾ 图标 → 选择值 → 确认
高级筛选工具栏 高级筛选 → 多条件 AND 组合

导入导出

  • 模板：下载空白导入模板（Excel 格式）
  • 导入：选择填好的 Excel 文件批量导入
  • 导出：按当前筛选条件导出 Excel

列宽调整

鼠标移到列表头右边线，拖动即可调整列宽。

报价计算器

工具栏 报价计算器：输入成本 → 设利润点数 → 自动算出含税/未税报价。支持 CNY/USD 切换。

样品登记

顶部导航 样品登记，功能与报价管理类似，用于记录样品信息。

手机版

顶部导航 手机版 或手机浏览器直接访问。

  • 搜索框输入关键词自动推荐品牌/频点/工厂快捷标签
  • 点击卡片 → 弹窗展示该物料全部报价
  • 底部 TabBar：查询 / 新增 / PC后台
  • 支持高级筛选、导出

数据显示规则

同款合并

以下 14 个技术字段完全相同的记录视为同款，仅在列表显示最低价那条：
物料编码、物料名称、规格、品类、品牌、尺寸、PIN脚、频点、负载、电压、模式、频偏、温度、最小包装

价格颜色

类型颜色
CNY 含税价红色 ¥0.5000
CNY 未税价橙色 ¥0.3200
USD 含税（折合）蓝色 ¥0.6960
USD 未税浅蓝 $0.0850

最低价规则

同款产品取 含税价 数字最低的那条（USD 自动按汇率折算比较）。

自动备份

每次关闭程序自动备份：
数据库备份 → data/backups/（保留 30 份）
Excel 备份 → data/excel-backups/（报价+样品各保留 10 份）

数据安全

  • API 写操作需 token 鉴权（自动生成）
  • 删除为软删除，可在回收站恢复
  • 安装版卸载时数据默认保留在 %APPDATA%/晶振报价管理系统/
  • 便携版数据在 exe 同目录 data/ 文件夹

远程访问（手机在外网查看）

推荐使用 Cloudflare Tunnel（免费）：

  1. 下载 cloudflared：https://github.com/cloudflare/cloudflared/releases
  2. 终端运行：cloudflared tunnel --url http://localhost:3266
  3. 得到公网地址如：https://xxx.trycloudflare.com
  4. 手机浏览器打开该地址即可
trycloudflare.com 地址每次重启 PC 会变。如需固定地址，注册 Cloudflare 免费账号 + 域名。

常见问题

导入显示成功但看不到数据？

关闭程序重新打开，可能是缓存问题。

为什么同款显示多条？

检查 14 个技术字段是否完全一致，特别是温度、最小包装等新增字段。

规格书上传后打不开？

规格书保存在 data/specs/，编辑记录时可删除重传。

批量删除删不干净？

确认没有列筛选条件残留，批量删除会按当前所有筛选条件执行。
